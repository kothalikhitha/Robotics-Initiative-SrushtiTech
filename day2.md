# Srushti Technologies Robotics Initiative — Day 02

## Topic of the Day (TOD): Robot Position Calculations
**Focus:** Solving Basic Robot-Position Calculations

### Key Learnings
- **Vectors:** Represent positions and directions in space.
- **Linear Transformations & Matrices:** Used to calculate robot movements and transformations.
- **Matrix Multiplication:** Represents composition of transformations.
- **Rotation Matrices:** Define orientation changes in 2D/3D space.
- **Determinant:** Provides insight into scaling and orientation effects of transformations.

### Understanding
Robot position calculations are built on linear algebra. By combining vectors, matrices, and transformations, we can model how robots move and orient themselves in 3D space with precision.
